# Aurelia Prime

Approved two-page character site: 18 artworks, eight fantasy/everyday pairings, and Woman / Man elder options.

## Hosting

Deploy this repository as a static HTML website in Hostinger. The document root is the repository root; no build command or package installation is needed. Entry page: index.html. Character viewer: characters.html. All paths are relative so a temporary domain can be changed later without rewriting the site.

## Files

- index.html: city landing and two-character preview
- characters.html: complete viewer, filters, search, dialogs and downloads
- assets/: approved city image and 18 character JPEGs
- credits.txt: artwork and prototype asset credits

Character artwork is still imagery. The older 3D prototypes are not part of this deployment.
